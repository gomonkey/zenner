# Zenner

**A daily planning and reflection app for people who want to live each day on purpose.**

Zenner isn't trying to replace your calendar or become another growing to-do list. It's a focused workspace for deciding, each day, what actually matters — then doing it, and reflecting on how it went.

---

## Why Zenner Exists

Most productivity apps optimize for convenience: recurring tasks, auto-scheduling, infinite backlogs, long-term plans that quietly go stale. These features are useful, but they also make it easy to operate on autopilot — checking boxes without ever really deciding what deserves your attention today.

Zenner starts from a different premise:

> **Every day deserves intentional planning.**

Instead of carrying tasks forward automatically or setting up recurring schedules, Zenner asks you to make a deliberate choice each morning: _what matters today?_ Planning isn't a one-time setup — it's a daily practice.

A few ideas run through the whole app:

- **Deep work vs. shallow work.** Deep work gets dedicated, non-negotiable time blocks on your calendar. Shallow work is the important-but-flexible stuff that needs to get done, just not at a specific time.
- **Days are records, not drafts.** You can adjust your plan freely while the day is happening. But once a day ends, you get a short window to reflect and make corrections — after that, it's archived. History doesn't get quietly rewritten.
- **Constraints over automation.** Zenner deliberately doesn't do everything a typical planner does. The goal isn't maximum productivity — it's awareness, clarity, and deliberate action.

## Core Views

### 📅 Daily View

A 24-hour planner for the day ahead:

- Schedule **time blocks** for deep, focused work
- Track important **unscheduled tasks** that don't need a fixed time
- Check in on daily **habits**

### 🗓️ Weekly View

A lightweight journal, not a second calendar:

- Reflect on each day of the week as it passes
- Set a **weekly focus** — the one thing that should guide the days ahead

### 🌙 Monthly View

A high-level overview, kept intentionally simple:

- Capture notes, milestones, and reminders
- See the shape of your month at a glance, without the clutter of a full calendar app

## Philosophy in Practice

| Zenner does                                      | Zenner intentionally avoids                          |
| ------------------------------------------------ | ---------------------------------------------------- |
| Daily, deliberate planning                       | Recurring tasks that repeat without a second thought |
| A clear split between deep and shallow work      | One flat, undifferentiated task list                 |
| A short, honest reflection window after each day | Endless editing of past days                         |
| A focused, minimal feature set                   | Automation that plans your day for you               |

## Tech Stack

Zenner is a full-stack project built to explore backend architecture, mobile-first frontend engineering, and cloud deployment:

- **Backend:** Spring Boot (Java)
- **Frontend:** React Native
- **Database:** PostgreSQL
- **Deployment:** AWS, with modern CI/CD and DevOps practices

This project doubles as a personal productivity tool and a portfolio piece — a real application built end to end, not just a toy example.
